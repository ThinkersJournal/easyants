# EasyAnts

The front door to the Ants: small Rust building blocks (ConfigurAnt, PersistAnt, CapAnt and more to come) that make
common jobs easy. Site: https://easyants.dev (domain registered 2026-10-28).

> Great software shouldn't be hard to build.

Plan: a static, script-free page of collapsed cards. Each card is a name and one sentence; opened, it shows a usage
example of ten lines or fewer, an install link and a link to that Ant's own site. Cards are built from a small data file
in each Ant's repository and the Ant's tested README example, so they cannot go stale. Released Ants get full cards;
Ants that are still placeholders sit in a "coming" row with a status label and no example. Nothing is built yet.
